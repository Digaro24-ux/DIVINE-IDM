DIDIVINE IDM
View on GitHub →

Download anything, faster.

A free, open-source download manager with a modern interface. Videos, music, image galleries and ordinary files. It runs on your own computer, so your downloads land in your own Downloads folder.

⬇ Download for Windows macOS Linux

Unzip, then double-click DIVINE-IDM. Your browser opens the app automatically. Windows may show a "SmartScreen" notice because the app isn't code-signed: choose More info → Run anyway.

⚡ Multi-threaded engine

Splits files into up to 16 parallel connections, with pause and resume that survives restarts.

🎬 Video & music sites

yt-dlp with automatic fallback to PyTube, You-Get, Lux and gallery-dl. Pick the quality: 144p to 4K, MP3 or M4A.

📱 Phone friendly

Converts to H.264/AAC MP4 when needed so Gallery and WhatsApp can play it, and can send files to your phone over Wi-Fi.

🖼️ Image galleries

Grab a whole gallery into one folder with a single link.

🗂️ Familiar layout

Category sidebar, list and card views, search, right-click menu, disk-space gauge.

🛠️ Network doctor

Detects dead proxies and blocked connections and tells you how to fix them.

Run from source (developers)

git clone https://github.com/YOU/REPO.git
cd REPO
python -m venv venv
venv\Scripts\activate        # macOS/Linux: source venv/bin/activate
python -m pip install -r requirements.txt
python app.py

Questions

Can I use it online, straight from this website?

No, and that is by design. This page is only a free static website, and websites can't save files into your Downloads folder, open your folders or use your ffmpeg. The app has to run on your computer. 127.0.0.1 always means "this computer", so the app's address (http://127.0.0.1:5001) only exists on a machine where DIVINE IDM is running.

Do I need a terminal?

Not with the downloads above: just double-click. The terminal steps are only for people running from source.

Is it legal?

The software is. What you download is your responsibility: only download content you own or have permission to download, and respect each site's terms.
